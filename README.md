# I AM HERE / 我在

An interactive internet art project exploring the delegation of decisions, speech and identity to AI. Read in English or Chinese, turn through the book and follow links to source material.

The site is static. Open `index.html`, or serve this directory with any static web server.

## Materials

Some conversation prompts and responses are selected from [WildChat-1M](https://huggingface.co/datasets/allenai/WildChat-1M), published by Ai2 under [ODC Attribution 1.0](https://opendatacommons.org/licenses/by/1-0/). The CSV file includes the selected records and source identifiers. Personal accounts, reports and legal materials link to their original publications. Some responses and the voice in the second reading are created for the artwork. Translations use machine translation.

The accompanying CSV files document work with the [SearchEnginesBookmarklet](https://medialab.github.io/SearchEnginesBookmarklet/), [Search Image Tagger](https://internetpoetics.neocities.org/search-image-tagger/) and [CSV Text Explorer](https://internetpoetics.neocities.org/csv-text-explorer/).

Project concept and direction by the student. OpenAI Codex assisted with source selection, translation, text and implementation.
